Sequence & Validation

How to collect a few fields as a simple sequence, then start checking that input makes sense. If you finish early, the "Going Further" section has two more checks to try.

Collecting Input as a Sequence

2 examples

BEAT 1 · THE ANALOGY

Think about signing up at a GP surgery or library — you're never asked for your name, then your address, then your name again. It's always the same fields, in the same order.

That's exactly what this code does: one input() line after another, in a fixed order, directly inside add_record() — no separate function for each field.

BEAT 2 · THE PATTERN

One field at a time, then a print at the end to prove it worked.

def add_record():
    name = input("Name: ")
    kayak = input("Kayak type: ")
    date = input("Hire date: ")

    print("Name:", name)
    print("Kayak:", kayak)
    print("Date:", date)
Expect: Each value printed back exactly as entered, in the same order it was collected

BEAT 3 · THINK ABOUT IT

Think: What would go wrong if the input() lines were in a different order to how you eventually want to store them?

Adding Validation

1 example

BEAT 1 · WHY BOTHER?

What could go wrong if a visitor types nothing at all for their name, or just hits enter? That's exactly what validation catches.

BEAT 2 · PRESENCE CHECK

Keep re-asking until something is actually entered — a while loop wrapped around the input.

def add_record():
    name = input("Name: ")

    while name == "":
        print("Name cannot be blank")
        name = input("Name: ")

    kayak = input("Kayak type: ")
    date = input("Hire date: ")
Expect: Pressing enter on an empty name re-prompts; typing anything moves on

BEAT 3 · GOING FURTHER

One solid presence check is a good goal for today. Finished and confident? Keep reading — two more checks below.

Going Further

extension

LENGTH CHECK

Make sure an answer isn't suspiciously short to be real — e.g. a kayak type of just one or two letters.

kayak = input("Kayak type: ")

while len(kayak) < 3:
    print("Please enter a full kayak type")
    kayak = input("Kayak type: ")
Expect: Typing "k" re-prompts; typing "kayak" or "double" moves on

RANGE CHECK

Make sure a number falls within sensible limits — e.g. hire hours between 1 and 8.

hours = int(input("Hours hired: "))

while hours < 1 or hours > 8:
    print("Hours must be between 1 and 8")
    hours = int(input("Hours hired: "))
Expect: Typing 0 or 12 re-prompts; typing 1–8 moves on
