Question 1 — rows of mixed values. What does this print?
table = [["a", 5], ["b", 7]]
print(table[1][0], table[0][1] + table[1][1])
Question 2 — the reset. What does this print?
grid = [[1, 2], [3, 4]]
for row in grid:
    total = 0
    for v in row:
        total = total + v
    print(total)
Question 3 — input. The user types 5. What happens?
qty = input("Quantity: ")
print(qty + 1)
Question 4 — recursion. What does this print?
def countdown(n):
    if n == 0:
        print("Go")
    else:
        print(n)
        countdown(n - 1)

countdown(3)
Hold that thought: today the rows hold different kinds of value — text, whole numbers, decimals — so types matter. And we find a row by its key.
