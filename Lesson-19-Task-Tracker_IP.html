def find_item(stock, code):
    for position in range(len(stock)):
        if stock[position][0] == code:
            return position
        else:
            return -1

Step 5: compare your explanation with a model one

Why check for -1 before del: -1 is how find_item says “not found” — but Python also reads -1 as a real position, the last row. Without the check, a code that isn’t found silently deletes the last item, with no error message.
