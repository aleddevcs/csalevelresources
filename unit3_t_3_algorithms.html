Algorithms & Programs

Interactive reference for Unit 3 Programming & Development.

Definition

An algorithm is a step-by-step set of instructions or rules designed to provide a solution to a specific problem.

Selection & Iteration

Selection: Logic paths based on conditions (e.g., IF, ELSE).
Iteration: Repeating instructions until a condition is met (e.g., WHILE, FOR).

Recursion

Recursion is a subroutine that calls itself. It requires a base case to stop and a recursive step to solve smaller parts of a problem.

02 Algorithm Library

Standard pseudo-code reference and logical explanations.

Bubble Sort

while i < len(arr)-1
  set j = 0
  while j < len(arr) - 1 - i
    if arr[j] > arr[j + 1]
      temp = arr[j]
      arr[j] = arr[j + 1]
      arr[j + 1] = temp
    end if
    j = j + 1
  end while
  i = i + 1
end while
  • Compares adjacent elements in a list.
  • Swaps elements if they are in the wrong order.
  • Smallest/Largest values "bubble" to their correct positions in multiple passes.
  • Time Complexity: O(n²) in worst case.

Insertion Sort

FOR index = 1 TO num_items - 1
  item_to_insert = items[index]
  position = index - 1
  WHILE position >= 0 AND items[position] > item_to_insert
    items[position + 1] = items[position]
    position = position - 1
  ENDWHILE
  items[position + 1] = item_to_insert  
NEXT index
  • Builds a sorted list one item at a time.
  • Picks the next unsorted element and shifts existing sorted elements to make space.
  • Inserts the element into its correct relative position.
  • Efficient for small or nearly sorted datasets.

Quick Sort

algorithm quickSort(myArray, indexLow, indexHi)
  set pivot = myArray[(indexLow + indexHi) DIV 2]
  set tmpLow = indexLow
  set tmpHi = indexHi
  while (tmpLow <= tmpHi)
    while (myArray[tmpLow] < pivot) set tmpLow = tmpLow + 1
    while (pivot < myArray[tmpHi]) set tmpHi = tmpHi - 1
    if (tmpLow <= tmpHi) then
      swap(myArray[tmpLow], myArray[tmpHi])
      set tmpLow = tmpLow + 1 
      set tmpHi = tmpHi - 1
    end if 
  end while
  if (indexLow < tmpHi) then quickSort(myArray, indexLow, tmpHi) 
  if (tmpLow < indexHi) then quickSort(myArray, tmpLow, indexHi)
end algorithm
  • Uses a "Divide and Conquer" recursive strategy.
  • Selects a pivot element to partition the list into two halves.
  • Reorders elements so those less than pivot go left, and greater go right.

Linear Search

WHILE current < LEN(items) AND found == False
  IF items[current] == search_item THEN
    found_index = current 
    found = True 
  ENDIF
  current = current + 1 
ENDWHILE
  • Checks every item in a list sequentially from start to finish.
  • Stops immediately when the target item is found.
  • The only choice for unsorted data.

Binary Search

WHILE first <= last AND found == False
  midpoint = (first + last) DIV 2
  IF items[midpoint] == search_item THEN 
    found_index = midpoint
    found = True
  ELSEIF items[midpoint] < search_item THEN
    first = midpoint + 1
  ELSE
    last = midpoint - 1
  ENDIF
ENDWHILE
  • Requires the list to be pre-sorted.
  • Repeatedly halves the search area by comparing target to the midpoint.
  • Extremely efficient for large datasets (O(log n)).

Dijkstra's Shortest Path

Note: Logic explanation.

  • Finds the shortest distance between a start node and all other nodes in a graph.
  • Maintains a table of "Smallest Known Cost" and "Previous Node".
  • Continually visits the unvisited node with the smallest cost, updating its neighbors.

algorithm sumOfDigits(n)
set sum = 0
while n > 0
set digit = n % 10 (mod)
set sum = sum + digit
set n = n // 10 (div)
end while
return sum

07 Big O Efficiency

★ Worked Example: Time Complexity 

Algorithm MatrixFill
for i = 1 to n do
   for j = 1 to n do
      set A[i][j] = i * j
   next j
next i
1

The outer loop (i) iterates through every row, executing n times.

2

The inner loop (j) iterates through every column n times for each of the outer loop's steps.

3

Total atomic operations = n × n = n2.

TIME COMPLEXITY: O(n2)

◈ Space Complexity

Measures the amount of memory needed relative to the input size.

O(1) - Constant Space

Memory usage doesn't grow with input.

O(n) - Linear Space

Memory grows with input (e.g. duplicating an array).
