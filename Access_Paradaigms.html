What is a Paradigm?

Think of a paradigm as a "style" or a "strategy." It's not just about the code you write; it's about how you approach solving the problem.

"Most problems can be solved using any paradigm, but the choice determines how fast, easy, or secure the solution is."

The House Metaphor

Imperative: "Lay brick 1, then brick 2. Apply mortar. Level it. Repeat." (Focus on **HOW**)
Declarative: "I need a two-story blue house with 3 windows." (Focus on **WHAT**)

1. Procedural Programming

This is a top-down approach. You break a problem into small, logical steps. It is the style most beginners learn first.

  • Sequence: The order of steps.
  • Selection: Making decisions (If/Else).
  • Iteration: Repeating steps (Loops).
Languages: C, BASIC, Pascal, Python

2. Object-Oriented (OOP)

Instead of just steps, we focus on data. We create "blueprints" (Classes) and make "real things" (Objects) from them.

Inheritance

Creating child classes from parents.

Encapsulation

Hiding data inside the object.

Languages: Java, C++, Python, Ruby

3. Event-Driven

The program sits in a Main Loop and waits for things to happen (Events). It doesn't run start-to-finish; it responds.

1
Event: User clicks or timer ends.
2
Listener: Program catches the event.
3
Handler: Code block runs in response.
Languages: JavaScript, C#, Visual Basic

4. Scripting

Small bits of code used to automate specific tasks. It's often used for the web or system maintenance.

Automation: Why do something manually 100 times when a 5-line script can do it in a second?

Languages: Bash, PowerShell, Python, PHP
