Stack & Queue Simulator

Stretch / preview of Lesson 2 · Representing stacks and queues with an array and pointers
Both use the SAME array – only the pointers differ

Stack – LIFO (Last In, First Out)

One pointer, top. Starts at -1 (empty). Push: top += 1; stack[top] = x. Pop: x = stack[top]; top -= 1.

Queue – FIFO (First In, First Out)

Two pointers, front and rear. Enqueue: rear += 1; queue[rear] = x. Dequeue: x = queue[front]; front += 1. Empty when front > rear.

Try these (pairs)

  1. Push Ben, Django, Anna, then pop once, then push Zoe. What is in the array now, and what is top? Notice that "Anna" is still in the array – why doesn't that matter?
  2. Pop the stack until you get an error. What is the error called? What is top when it happens?
  3. Fill the stack completely and try one more push. What is that error called?
  4. Enqueue five names and dequeue two. Which slots are wasted? Why is a simple linear queue a problem, and what do you think a circular queue does about it?
  5. Exam question [4]: "Explain the differences between stack and queue data structures." Write four distinct points using the words LIFO, FIFO, top, front, rear, push, pop, enqueue, dequeue.
