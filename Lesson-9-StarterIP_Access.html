2Quick retrieval — Lesson 8

What does range(5) give you?
0, 1, 2, 3, 4 — five numbers, starting at zero.
What does .items() do in a dictionary loop?
It gives you the key and the value together, each time round the loop.
What does an accumulator need to be set to before the loop starts?
A starting value — usually 0 — set before the loop, then updated each time round it.
Why was a for loop the right choice in Lesson 8 — what did we know in advance?
We knew how many times it would run — a set range, or every item in a dictionary. That's what makes it determinate.

→Today we're building on this

  • Indeterminate loops — when you don't know how many times it will run
  • Validation loops — keep asking until the input is valid
