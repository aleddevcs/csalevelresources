Quick-Fire Python Recap

Short, live-coded beats to reactivate fluency fast. Each beat has a prompt to say out loud, code to type together, and the output to check for. This isn't a re-teach — keep energy high and move on as soon as the class has it.

Variables & Data Types

~3 minutes

BEAT 1 · DECLARE & IDENTIFY

Say: "Let's declare a few variables together — call out the data type before I check it."

# live-code together
name = "Aled"
age = 30
pi = 3.14
is_teacher = True

print(type(name), type(age), type(pi), type(is_teacher))
Expect: <class 'str'> <class 'int'> <class 'float'> <class 'bool'>

BEAT 2 · THE TYPE TRAP

Cold-call: "What happens if I add a string and an int?"

score = "10"
print(score + 5)
Expect: TypeError — then fix live: int(score) + 5

Input / Output

~3 minutes

BEAT 1 · INPUT IS ALWAYS A STRING

Say: "input() always returns a string — even if you type a number. Let's prove it."

age = input("Enter your age: ")
print(type(age))
Expect: <class 'str'> — even after typing e.g. 17

BEAT 2 · CONVERT TO DO MATHS

Say: "So if we want to do maths with it, we have to convert it first."

age = int(input("Enter your age: "))
print(age + 1)
Expect: Their age + 1, as a whole number

Selection

~4 minutes

BEAT 1 · IF / ELIF / ELSE

Say: "Let's build a simple grade checker — call out what each branch should do before I type it."

mark = int(input("Enter mark: "))

if mark >= 80:
    print("Distinction")
elif mark >= 50:
    print("Pass")
else:
    print("Fail")
Test with: 90 → Distinction, 60 → Pass, 30 → Fail

BEAT 2 · TRACE THE BOUNDARY

Discuss: No new code — ask: "What happens if mark is exactly 50? Trace it through the conditions together."

Iteration

~4 minutes

BEAT 1 · FOR — KNOWN REPEATS

Say: "for loops are for when we know exactly how many times to repeat."

for i in range(5):
    print(i)
Expect: 0 1 2 3 4, each on its own line

BEAT 2 · WHILE — UNKNOWN REPEATS

Say: "while loops are for when we don't know how many times — but that means we have to give it a way to stop. This is exactly the pattern our Section B menu will use later."

option = ""
while option != "q":
    option = input("Press q to quit: ")
print("Done")
Expect: Keeps asking until the user types q, then prints Done
