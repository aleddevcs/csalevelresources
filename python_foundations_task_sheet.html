How this lesson works

  1. Work through the steps of the ladder in order — each one uses what you built in the last.
  2. Test your code after every few lines. Don't write twenty lines and then run it for the first time.
  3. Stuck for more than a couple of minutes? Try the linked W3Schools page for that step before putting your hand up.
  4. Save each challenge as its own file: step1.py, step2.py, and so on — you'll want them later.
  5. Near the end we'll put some solutions up on the whiteboard and walk through them together, so keep your code tidy enough to explain.

The Bouncer

selectioniterationvalidation

Goal: reject bad input and keep asking until you get something valid — this shows up in almost every exam question.

  • Ask the user to enter their age.
  • If the age is below 11 or above 19, print an error message and ask again.
  • Keep looping until a valid age is entered, then print "Welcome in!"
# step2.py
valid = False
while ___:
    age = int(input("..."))
    if ___:
        print("...")
    else:
        valid = ___

print("...")

3

Menu Machine

selectioniterationprogram structure

Goal: build the menu-driven shape that almost every Section B program uses.

  • Display a menu with three options: 1. Add, 2. Search, 3. Quit.
  • Take the user's choice and use if / elif to branch — for now, each option can just print which one was chosen.
  • Keep looping and re-showing the menu until the user chooses Quit.
# step3.py
choice = ""
while choice != ___:
    print("1. Add")
    print("2. Search")
    print("3. Quit")
    choice = input("...")

    if choice == "1":
        print("...")
    elif choice == "2":
        print("...")
    elif choice == "3":
        print("...")
    else:
        print("...")

4

List Logger

listsiterationsearching

Goal: store several records in memory and search them — no starter code this time, you're building from scratch.

  • Use a loop to collect 5 names from the user, adding each one to a list.
  • Once all 5 are collected, ask the user to enter a name to search for.
  • Loop through the list and count how many times that name appears — print the count.
  • Print "Found" if the count is above 0, otherwise "Not found".
W3Schools: Lists → W3Schools: for loops →
5

File Writer

file handlingiteration

Goal: get your list onto disk. This is the exact skill Section B calls "storing details on disk."

  • Take the list of 5 names from Step 4 (or collect them again).
  • Open a text file called names.txt for writing.
  • Write each name to the file on its own line.
  • Close the file, then open names.txt yourself and check the names are actually there.

File Reader — and the full build

stretchfile handlingall constructs

Goal: read stored data back and search it — then combine everything into one program.

  • Open names.txt for reading and loop through each line, printing it.
  • Ask the user for a name to search for, and count how many lines in the file match it.
  • Full build: combine Steps 3, 5 and 6 into one menu-driven program — Add appends a name to the file, Search reads the file and reports the count, Quit ends the program. This is a miniature version of a real Section B question.
