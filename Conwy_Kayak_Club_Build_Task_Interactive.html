Before you start

Conwy Kayak Club hires out kayaks and paddles to visitors. Staff need a program that lets them record the details of a new hire, look up a hire later by the visitor's name, and exit safely.

Get out your Lesson 1 planning sheet for the fields you identified. Open your menu_shell file and find add_record() — that's where all of today's work goes.

1

Build the Input Sequence

Using your Lesson 1 plan, add one input() line inside add_record() for each field a new kayak hire needs (e.g. visitor name, kayak type, hire date). Keep them in the same order as your plan.

Finish with a print statement for each value, so you can see everything you've collected.

2

Add Validation

Pick one field from your sequence and add a presence check to it, using the while loop pattern from the reference sheet: keep re-asking until something is actually entered.

One good check, done properly, is a success for today — don't rush to add more.

Finished early? Try a second check on a different field — the Student Reference Sheet has a length check and a range check example you can adapt.
