Before you start: your Lesson 3 menu shell should run and save a record to kayak_hires.txt. Everything today changes that same file. The Lesson 4 prompt sheet has every pattern if you need a reminder.

1

Refactor Your Validation

Rewrite the validation for name, kayak type and hire date using the new pattern: one loop per field, a valid flag and an if / elif chain.

Keep the checks you already have (presence, lookup, format) and add a maximum length to every field. The maximum length is the width you pad to with .ljust().

Common slip Forgetting valid = False before a field's loop. The flag is still True from the last field, so the loop never runs.
2

Upgrade Your Save Code

Swap your open / write / close lines for a with block, and make the confirmation worth reading — say who was saved and where.

3

Write retrieve_record()

Ask for a visitor's name, search kayak_hires.txt line by line, slice out each field and print every hire that matches. Handle two situations: nothing matches, and the file doesn't exist yet.
