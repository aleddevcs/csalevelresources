Advanced Arithmetic
The Process: To calculate A - B, we calculate A + (-B).
  1. Take the subtrahend (B).
  2. Convert it to negative using Two's Complement (flip bits and add 1).
  3. Add this value to the minuend (A).
  4. Ignore any final carry bit if it exceeds the bit length.
