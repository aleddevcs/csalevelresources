1

Plan It, Then Code It

The monitor asks for a salinity reading again and again until the user enters 100. For each reading it prints the right message. When 100 is entered it prints “program terminated”.

Write the algorithm as pseudocode first — plain steps, not Python. Then code the loop and the if / elif chain in azsalt.py. No file work yet.

The rules
If the reading is…Print
below 0 or above 10fault detected
above 6add water
4 or morestop addition
below 1double the salt addition
below 2add salt
anything elsesalinity within range

The rules leave gaps for real numbers, so you decide what happens in between — and say so in a comment (Part 4).

Common slips A range test placed before a more extreme one (0.5 prints “add salt”), no fault check at the top (12 prints “add water”), and no second input() at the bottom of the loop — it never ends.

Store, Confirm, Retrieve

Store each reading (not 100) in saltResult.txt. Only the last reading matters, so use write mode. Confirm each save on screen. When the loop has ended, retrieve the last reading and display it.
