Upgrading Validation

2 examples

BEAT 1 · THE PATTERN

One flag, one loop and one if/elif chain per field. The field is only valid when every rule has passed, and each broken rule prints its own message.

valid = False
while valid == False:
    name = input("Name: ")
    if name == "":
        print("Name cannot be empty.")
    elif len(name) > 20:
        print("Name must be 20 characters or fewer.")
    else:
        valid = True
Expect:Blank input prints the empty message; 25 letters prints the length message; a normal name moves on.

BEAT 2 · MORE RULES, SAME LOOP

To add a rule, add an elif. Keep the order: empty first, then type or format, then length.

valid = False
while valid == False:
    date = input("Hire date (dd/mm/yyyy): ")
    if date == "":
        print("Date cannot be empty.")
    elif date.count("/") != 2:
        print("Date must be in the format dd/mm/yyyy.")
    elif len(date) > 10:
        print("Date must be 10 characters or fewer.")
    else:
        valid = True
Expect:Each broken rule shows its own message; only a valid date ends the loop.
Think: Why must the maximum length match your .ljust() width?
Common slip: Forgetting valid = False before the next field's loop — the loop never runs because the flag is still True.

Context Managers

2 examples

BEAT 1 · WITH OPEN

The file closes itself when the with block ends, even if something goes wrong. There is no file.close() to forget.

with open("kayak_hires.txt", "a") as file:
    file.write(record + "\n")

print("Saved", name, "to kayak_hires.txt")
Expect:Two records give two lines in kayak_hires.txt, and the confirmation says what was saved and where.
Remember: Append mode creates the file if it doesn't exist yet. A descriptive confirmation message earns its own mark.

BEAT 2 · THE OLDER STYLE (IN THE EXAM)

The starter code in 'complete the code' does the same job like this. You need to be able to read it and fill in the gaps.

fileObject = open("kayak_hires.txt", "a")
fileObject.write(record + "\n")
fileObject.close()
try:
    fileObject = open("kayak_hires.txt", "r")
except IOError:
    print("No file to read")
else:
    while True:
        record = fileObject.readline()
        if record == "":
            fileObject.close()
            break
        # ...check the fields in record here...
Expect:Open, read a line at a time, stop when readline() returns an empty string, close.

Retrieving a Record

3 steps

BEAT 1 · READ AND SLICE

Read the file one line at a time, slice out the name, .strip() the padding and compare it to your search key.

search_name = input("Visitor name: ")
found = False

with open("kayak_hires.txt", "r") as file:
    for line in file:
        if line[0:20].strip() == search_name:
            print("Name:", line[0:20].strip())
            print("Kayak:", line[20:35].strip())
            print("Date:", line[35:45].strip())
            found = True
Expect:A record saved once prints once; saved twice prints twice, each with labelled fields.
Think: Where do 0, 20, 35 and 45 come from? Check them against your own .ljust() widths.

BEAT 2 · WHEN NOTHING MATCHES

If found is still False after the loop, nothing matched, so tell the user.

if found == False:
    print("No matching hire found.")
Expect:A name that isn't in the file prints the message once, after the whole file has been checked.

BEAT 3 · WHEN THERE IS NO FILE

Opening a file that doesn't exist crashes with FileNotFoundError. Wrap the read in try/except.

try:
    with open("kayak_hires.txt", "r") as file:
        for line in file:
            ...   # same loop as before

    if found == False:
        print("No matching hire found.")
except FileNotFoundError:
    print("No hires saved yet.")
Expect:With the file missing: "No hires saved yet." With the file present: normal results or "No matching hire found."
Common slip: Putting the found check after the try/except prints two messages when the file is missing. Keep it inside the try.

Going Further

extension

COUNT THE MATCHES

Count how many hires match and print the total.

count = 0

with open("kayak_hires.txt", "r") as file:
    for line in file:
        if line[0:20].strip() == search_name:
            count += 1

print(count, "hire(s) found for", search_name)
Expect:"2 hire(s) found for Aled" when that name has been saved twice.

if line[0:20].strip().lower() == search_name.lower():
Expect:Searching for "aled" finds "Aled".
