Key terms

Collision — two keys hash to the same index.
Linear probing — move forward to the next free slot.
Separate chaining — store colliding items in a linked list at that index.
Direct access — retrieving a value straight from its hashed index.

Hash table — Separate Chaining

Each row is one index. A colliding item is chained onto the end of that index's linked list.
