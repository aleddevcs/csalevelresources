Linked List Manipulator

Insert and delete nodes in a sorted linked list, and see exactly which pointers change — the same skill examiners ask you to show by redrawing a diagram.

Your task

  1. Click Load example to start with the list A → C → G → L.
  2. Type E into the box and click Insert. Read the step log — which node's pointer changed?
  3. Now delete C using the × on its node. Check how A's pointer is rewired.
  4. On paper, redraw both diagrams exactly as you would in an exam answer — every arrow, including the null at the end.
  5. Reset the list, add at least 5 values of your own choosing (one at a time), and try to predict where each one will land before you click Insert.
  6. Attempt the exam-style question at the bottom without the tool, then use it to self-check.

Add / remove a node

New nodes are inserted automatically in alphabetical order — exactly like the sorted linked list in your notes. Click the × on any node to delete it.

Exam tips

  • Always draw the pointer arrows explicitly, including the final arrow to null / end of list.
  • You never shift the other data along like an array — only the pointers of the affected node(s) change.
  • Marks are usually split: one for the node in the correct position, one for correctly redrawn arrows.
  • If the head node itself changes, say so — the start pointer must be redrawn too.

Linked list view

Exam-style question

The diagram shows a linked list holding data in alphabetical order: A → C → G → L → (null)

(a) Redraw the linked list after the data item 'E' has been inserted. [2]

(b) Redraw the amended linked list after the data item 'C' has been deleted. [2]
