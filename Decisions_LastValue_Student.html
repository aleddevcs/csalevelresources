Decisions in the Right Order

3 steps

BEAT 1 · ONLY THE FIRST TRUE CONDITION RUNS

In an if / elif chain, once one condition is true the rest are skipped. So an earlier condition can catch a case that was meant for a later one.

if reading > 6:
    print("add water")
elif reading >= 4:
    print("stop addition")
elif reading < 2:
    print("add salt")
elif reading < 1:
    print("double the salt addition")
else:
    print("salinity within range")
Expect:0.5 prints "add salt" (it should double); 12 prints "add water" (it should be a fault).
Think: What do the two failures have in common?

BEAT 2 · MOST EXTREME FIRST

Start with the case that has to override everything — the fault. Then work from the extremes inwards.

if reading < 0 or reading > 10:
    print("fault detected")
elif reading > 6:
    print("add water")
elif reading >= 4:
    print("stop addition")
elif reading < 1:
    print("double the salt addition")
elif reading < 2:
    print("add salt")
else:
    print("salinity within range")
Expect:0.5 now doubles; 12 is a fault; exactly 4 and 6 give "stop addition"; exactly 10 gives "add water".
Common slip: Putting a range test before a more extreme one, or forgetting the fault check at the top.

BEAT 3 · A LOOP THAT ENDS ON 100

Take one reading before the loop, test it in the loop condition, and take the next reading at the bottom. float() turns the text from input() into a real number.

reading = float(input("Reading (100 to quit): "))

while reading != 100:
    ...   # the if / elif chain

    reading = float(input("Reading (100 to quit): "))

print("program terminated")
Expect:100 first: the loop never runs and "program terminated" prints at once.
Common slip: Leaving out the second input() — the same reading is tested forever and the loop never ends.

Plan It First

2 steps

BEAT 1 · STEPS, NOT CODE

Pseudocode is the algorithm in plain steps, using words like INPUT, OUTPUT, IF and WHILE. Here is the layout, on an unrelated example:

INPUT guess
WHILE guess is not "open"
    OUTPUT "wrong - try again"
    INPUT guess
END WHILE
OUTPUT "welcome"
Remember: The exam asks for the algorithm in Section A and the code in Section B — so planning first is a real exam skill.

Store and Recall the Last Value

3 steps

BEAT 1 · WRITE MODE KEEPS ONLY THE LAST

Records were appended so every one was kept. Here only the most recent reading matters, so use write mode: it replaces whatever was in the file.

with open("saltResult.txt", "w") as file:
    file.write(str(reading))
print("Stored", reading, "in saltResult.txt")
Expect:Whatever you enter, the file only ever holds the latest reading.
Remember: This goes inside the loop, after the chain. 100 is the stop signal, not a reading, so it is never stored.

BEAT 2 · RETRIEVE AFTER THE LOOP

When the loop has ended, read the file back — and plan for there being nothing to read.

try:
    with open("saltResult.txt", "r") as file:
        last = file.read()
    print("Last reading stored:", last)
except FileNotFoundError:
    print("No reading stored yet.")
Expect:Readings 5, 12, 0.5 then 100: "Last reading stored: 0.5". Entering 100 straight away: "No reading stored yet."

BEAT 3 · THE STRUCTURE

How the three parts fit together — fill in the gaps with your own code:

reading = float(input("Reading (100 to quit): "))

while reading != 100:
    ...   # your if / elif chain

    ...   # store the reading (write mode) and confirm it

    reading = float(input("Reading (100 to quit): "))

print("program terminated")

...       # retrieve the last reading (with try / except)
Common slip: Forgetting str() — write() only accepts text. And using append mode for a value that should be overwritten.

Mini Calculator

patterns to reuse

BEAT 1 · THE NUMBERS: TYPE BEFORE RANGE

The numbers must be whole numbers from 0 to 9. Check it's a number first, then convert and check the range — last lesson's rule.

valid = False
while valid == False:
    first = input("First number (0-9): ")
    if not first.isdigit():
        print("Enter a whole number.")
    elif int(first) > 9:
        print("Enter a number from 0 to 9.")
    else:
        valid = True
first = int(first)
Expect:"x", "-3" and "2.5" all give "Enter a whole number."; "10" gives "Enter a number from 0 to 9."

BEAT 2 · THE OPERATOR AND THE ANSWER

Check the operator is one of the allowed choices, then use an if / elif chain to work out the answer.

valid_operators = ["+", "-", "*"]
valid = False
while valid == False:
    operator = input("Operator (+, -, *): ")
    if operator not in valid_operators:
        print("Choose +, - or *.")
    else:
        valid = True

if operator == "+":
    answer = first + second
elif operator == "-":
    answer = first - second
else:
    answer = first * second
print("Answer:", answer)
Expect:3 and 4 with + gives 7; with - gives -1; with * gives 12.
Common slip: Forgetting int(): input() gives text, so "3" + "4" is "34", not 7.
first = input("First number: ")     # "3"
second = input("Second number: ")   # "4"
print(first + second)               # 34  - joined as text, not added

BEAT 3 · STORE AND RECALL THE LAST ANSWER

This is the same pattern as the salinity program: write mode to store, and read it back to recall — with try / except in case there isn't a file yet.

Going Further

extension

CLEAR THE SCREEN

In a text program, "clear the screen" can be as simple as printing a lot of blank lines:

print("\n" * 30)   # pushes the old output off the screen
Expect:The earlier output scrolls out of view.

A RUNNING AVERAGE

Output the current reading and the average each time, as in the Section A algorithm:

total = 0
count = 0
reading = float(input("Reading (100 to quit): "))
while reading != 100:
    total = total + reading
    count = count + 1
    average = total / count
    print("Current:", reading, "Average:", round(average, 1))
    reading = float(input("Reading (100 to quit): "))
Expect:Readings 4, 6, 5 then 100: "Current: 4.0 Average: 4.0", "Current: 6.0 Average: 5.0", "Current: 5.0 Average: 5.0".

INPUT THAT SURVIVES TEXT

If someone types text instead of a number, float() crashes. Wrap it so the program asks again — use it for each reading:

valid = False
while valid == False:
    try:
        reading = float(input("Reading (100 to quit): "))
        valid = True
    except ValueError:
        print("Please enter a number.")
Expect:"abc" or an empty line prints "Please enter a number." and asks again.
