Giving feedback? Prompts to make it specific

Vague feedback ("looks good") isn't useful to log. Try finishing one of these instead:

  • "A function this system doesn't have yet that could help is…" — suggest something concrete, e.g. a search filter, a confirmation email, an admin report.
  • "Something about the scope that's still unclear is…" — point at a sentence that could mean two different things.
  • "A limitation I don't think has been mentioned is…" — what might still go wrong or be left out?
  • "The part I'd build first is… because…" — help them think about priority, not just a wish-list.
