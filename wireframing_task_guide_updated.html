Wireframing Task Guide

In this task, you will create a simple homepage wireframe for a website concept of your choice. You are not creating the final design yet. Instead, you are planning the layout so you can decide where each section of the page should go before you build it properly later.

Planning first Layout only No colours needed Use Figma or paper
Task Overview

What you need to do

Create a homepage wireframe for one simple website concept. Your wireframe must show the main structure of the page and where the user will find key content.

Choose one website idea:

Fast food website Gaming website Pet adoption centre Gym / fitness website Movie streaming site
Do not worry about making it look polished yet. The aim is to focus on structure, layout and navigation.

Step-by-step guidance

How to complete the task

Step 1 – Pick one simple website idea

Choose one of the website concepts above. Keep it simple. The goal is not to plan a full business website, but to practice laying out a homepage clearly.

Step 2 – Decide what content should appear on the homepage

Think about what a user should see first. For example, a homepage usually includes a title or logo, a navigation bar, a large hero section, some information, and a footer.

Ask yourself: What would a user expect to find immediately when they arrive on this website?

Step 3 – Add the main structure

Start by creating the large sections of the page. Most homepages include:

  • Header
  • Navigation bar
  • Hero image or banner
  • One or more content sections
  • Footer

Step 4 – Add labels to each section

You do not need real images or final text. Instead, use labels such as Hero Image, Welcome Text, Featured Products or Contact Info.

Step 5 – Keep the wireframe simple

A wireframe is a rough plan. It should use simple boxes, placeholders and labels. Avoid spending time on colours, fancy fonts or detailed graphics.

Step 6 – Review your layout

Check whether the page is easy to follow from top to bottom. The user should be able to tell:

  • What the website is about
  • Where the navigation is
  • What the important content is

Success criteria

What a good answer looks like

A good wireframe will:

  • Be neat and easy to understand
  • Show a clear page structure
  • Include obvious navigation
  • Use labels to explain each section
  • Make sense for the chosen website idea
Common mistakes:
  • Adding too much detail
  • Forgetting the navigation bar
  • Not including enough content sections
  • Trying to make it look finished instead of planned

Extension

Stretch challenge

If you finish early, improve your wireframe by adding one or more of the following:

  • A call-to-action button such as Book Now or Join Today
  • A third content section
  • Better spacing between sections
  • A clearer user journey from top to bottom
Stretch aim: make the layout feel more logical and professional without turning it into a full final design.
Final reminder

Before you finish

Make sure your wireframe is a plan, not a polished final webpage. The purpose of this task is to help you understand how web pages are structured before you move into a more detailed design or build stage.
