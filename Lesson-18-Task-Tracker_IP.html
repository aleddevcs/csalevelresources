Adding: append takes one thing. Put the four values in one list: stock.append([code, name, quantity, price]).

Deleting: start with position = -1. Loop with for i in range(len(stock)); when the code matches, set position = i. After the loop, if position is not -1, delete that row.

Printing the name: pop gives the row back — removed = stock.pop(position) — so removed[1] is its name.

Step 6: compare your explanation with a model one

Why search before deleting: a delete needs to know which position, and the code might not exist — so we find the position first and only delete if we found one.

Why delete after the loop: deleting while the loop is still running would shorten the list under it. Find first, then delete once.
