Variables & Data Types

2 examples

BEAT 1 · DECLARE & IDENTIFY

Every value in Python has a type. Python works this out automatically the moment you create a variable — try it and check each type.

# live-code together
name = "Aled"
age = 30
pi = 3.14
is_teacher = True

print(type(name), type(age), type(pi), type(is_teacher))
Expect: <class 'str'> <class 'int'> <class 'float'> <class 'bool'>

BEAT 2 · THE TYPE TRAP

Python won't automatically convert between types. Mixing text and numbers causes an error — run this and see what it says.

score = "10"
print(score + 5)
Expect: TypeError — then fix live: int(score) + 5

Input / Output

2 examples

BEAT 1 · INPUT IS ALWAYS A STRING

input() always gives you back a string — even if the user types a number. Try it and check the type.

age = input("Enter your age: ")
print(type(age))
Expect: <class 'str'> — even after typing e.g. 17

BEAT 2 · CONVERT TO DO MATHS

To do maths with an input, you have to convert it first — usually with int() or float().

age = int(input("Enter your age: "))
print(age + 1)
Expect: Their age + 1, as a whole number

Selection

2 examples

BEAT 1 · IF / ELIF / ELSE

if / elif / else lets your program choose between outcomes based on a condition. Try all three test values below.

mark = int(input("Enter mark: "))

if mark >= 80:
    print("Distinction")
elif mark >= 50:
    print("Pass")
else:
    print("Fail")
Test with: 90 → Distinction, 60 → Pass, 30 → Fail

BEAT 2 · TRACE THE BOUNDARY

Think: What happens if mark is exactly 50? Trace it through the conditions yourself — which branch does it take, and why?

Iteration

2 examples

BEAT 1 · FOR — KNOWN REPEATS

for loops are for when you know exactly how many times to repeat.

for i in range(5):
    print(i)
Expect: 0 1 2 3 4, each on its own line

BEAT 2 · WHILE — UNKNOWN REPEATS

while loops are for when you don't know how many times — but that means you have to give it a way to stop. This is exactly the pattern you'll use to build the Section B menu later in this unit.

option = ""
while option != "q":
    option = input("Press q to quit: ")
print("Done")
Expect: Keeps asking until the user types q, then prints Done
