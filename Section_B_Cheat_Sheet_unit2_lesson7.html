B INPUT + LENGTH CHECK

valid = False
while valid == False:
    ref = input("Reference (5 characters, e.g. BK123): ")
    if ref == "":
        print("The reference cannot be empty.")
    elif len(ref) != 5:                 # exact length
        print("It must be exactly 5 characters.")
    else:
        valid = True
# also: len(x) > 25 (maximum) | not x.isdigit() (digits only)
# range: isdigit() FIRST, then int(x) < 1 or int(x) > 8

C SAVE + FEEDBACK

record = ref.ljust(5) + title.ljust(25)     # 5 + 25 = 30 characters
with open("books.txt", "a") as file:        # creates it if missing
    file.write(record + "\n")               # \n ends the line
print("Saved", title, "to books.txt")       # WHAT was saved, and WHERE

D FIND ONE RECORD

key = input("Reference to find: ")
try:
    with open("books.txt", "r") as file:
        found = False
        for line in file:
            if line[0:5] == key:                  # slice = the first field
                print(line[5:30].strip())         # strip() removes the padding
                found = True
        if found == False:
            print("No record found for", key)
except FileNotFoundError:
    print("No records saved yet.")
Any file access is accepted — this reads line by line. The older style (open, readline(), close(), except IOError) is fine too.

HCI — WHAT ‘FIT FOR PURPOSE’ LOOKS LIKE

  • Prompts say what to type, with an example
  • A numbered menu that loops until Exit
  • Errors say what is wrong and what to do
  • Confirmation names the data that was saved
  • Output is labelled, not a raw line from the file
  • ‘Not found’ and ‘no file yet’ don't crash it
  • Says goodbye

COMMON SLIPS

  • input() gives text — int() or float() before any maths or number comparison.
  • Joining a number to text needs str(): "Total " + count crashes.
  • Forgot "\n" — the records run together on one line.
  • "a" adds to the end; "w" replaces everything.
  • Slice ends are excluded: [0:5] is 5 characters, and must match the ljust widths.
  • Reset CountGot = 0 for every record.
  • Type before range: isdigit() first, then int().
  • Test it with bad input before you stop.

BEFORE YOU FINISH

  • Both files saved with the exact names from the paper
  • The program runs — and you tried it with bad input
  • All three questions attempted

Q1 COMPLETE THE CODE — 4 MARKS

Don't guess. 1 Find the sibling lines (same code, one field over) → 2 copy the pattern → 3 still stuck? Ctrl+F — the missing word is almost always somewhere else in the file. A placeholder inside quote marks is a variable: no quotes.
The gap is…Look here
1A name that must match its neighbourscopy it from the sibling block
2A method name — .get, .ljust, .showinfothe same method is on the lines around it
3A counter — CountGot +=1the sibling lines use the same counter
4A function namemust match the Button's command=
5A file namemust match where the file was opened to save

THE COUNT ROUTINE IN ONE BREATH

  • CountNeeded = how many boxes were filled in.
  • CountGot = how many of those match this record.
  • The record counts only when CountGot == CountNeeded.
  • Reset CountGot = 0 at the top of the loop, for every record.
