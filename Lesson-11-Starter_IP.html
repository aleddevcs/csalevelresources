Two quick parts. First, predict what three short snippets print — without running them. Then place yourself honestly on the Lesson 10 programme, so you know what to do next.

Part A

1Predict the output

Snippet 1 — what does it print?
for a in range(1, 3):
    for b in range(1, 3):
        print(a, b)
Four lines: 1 1, then 1 2, then 2 1, then 2 2. The inner loop runs completely for every pass of the outer loop.
Snippet 2 — what does it print?
total = 0
for n in range(1, 5):
    if n > 2:
        total = total + n
print(total)
7 — only 3 and 4 pass the if, so the total becomes 3 + 4.
Snippet 3 — what is printed at the end?
count = 0
for i in range(3):
    for j in range(4):
        count = count + 1
print(count)
12 — the inner loop runs 4 times for each of the 3 outer passes, so the counter goes up 3 × 4 = 12 times.
