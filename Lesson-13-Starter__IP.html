Part B

2Predict the function

Question 1 — what does this print?
def grade_time(seconds):
    if seconds < 60:
        return "fast"
    elif seconds < 70:
        return "steady"
    else:
        return "slow"

times = {"Ann": 62, "Bo": 75, "Cy": 58}
for name, seconds in times.items():
    print(name, grade_time(seconds))
Three lines: Ann steady, Bo slow, Cy fast. The loop calls grade_time once for each runner, and prints what it returns.
