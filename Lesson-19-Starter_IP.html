Part A

Question 1 — removing. What does this print?
items = ["a", "b", "c", "d"]
del items[1]
print(items, len(items))
Question 2 — a function. What does this print?
def double(n):
    return n * 2

print(double(3) + double(4))
Question 3 — a grid. What does this print?
grid = [[1, 2, 3], [4, 5, 6]]
print(grid[1][2], len(grid[0]))
Question 4 — recursion. What does this print?
def total(n):
    if n == 0:
        return 0
    return n + total(n - 1)

print(total(4))
Hold that thought: yesterday you wrote the same loop to find a row, again to change it, and again to delete it. Today you write it once — as a function — and call it.
