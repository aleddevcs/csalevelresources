1Quick-fire retrieval

What naming convention do we use for constants?
ALL_CAPS — e.g. PI, MAX_SCORE. Python doesn't enforce it; it's a convention.
What type does input() always return, no matter what's typed?
A string (str) — even if the user types digits, you need to convert it yourself.
What does int(3.9) return?
3 — int() truncates, it does not round.
What's the difference between int("42") and int("hello")?
int("42") works and returns 42. int("hello") raises a ValueError — not all text can become a number.
