Validation Techniques

Every WJEC Section B validation check, explained once and shown once, using the same Conwy Kayak Club fields throughout. Lesson 2 covered the presence check in depth; the rest build on exactly the same while-loop pattern.

1

Presence Check

Catches: the field being left completely blank — the user just pressed enter.

name = input("Name: ")

while name == "":
    print("Name cannot be blank")
    name = input("Name: ")
Expect: Pressing enter with nothing typed re-prompts; any text moves on
2

Length Check

Catches: an answer that's technically not blank, but too short (or too long) to be real.

kayak = input("Kayak type: ")

while len(kayak) < 3:
    print("Please enter a full kayak type")
    kayak = input("Kayak type: ")
Expect: Typing "k" re-prompts; typing "kayak" moves on
Exam tip: You can check a maximum length the same way with len(field) > x — useful if a data structure table gives a fixed field length.
3

Range Check

Catches: a number that's outside sensible real-world limits.

hours = int(input("Hours hired: "))

while hours < 1 or hours > 8:
    print("Hours must be between 1 and 8")
    hours = int(input("Hours hired: "))
Expect: Typing 0 or 12 re-prompts; typing 1–8 moves on
Exam tip: Range checks need a number type first — convert with int() or float() before comparing, or Python will error on text input.
4

Format Check

Catches: input that isn't in the right shape or pattern, even if it isn't blank, too short, or out of range.

date = input("Hire date (dd/mm/yyyy): ")

while date.count("/") != 2:
    print("Date must be in the format dd/mm/yyyy")
    date = input("Hire date (dd/mm/yyyy): ")
Expect: Typing "14092026" re-prompts; typing "14/09/2026" moves on
Exam tip: This is a simplified format check — it confirms the right number of slashes, not that the date itself is real. That's normally enough for Section B marks.
5

Lookup Check

Catches: an answer that isn't one of a fixed, known list of valid options.

valid_kayaks = ["Single", "Double", "Touring"]
kayak = input("Kayak type (Single, Double, Touring): ")

while kayak not in valid_kayaks:
    print("Please enter a valid kayak type")
    kayak = input("Kayak type (Single, Double, Touring): ")
Expect: Typing "Canoe" re-prompts; typing "Double" moves on
Exam tip: Python is case-sensitive here — "double" won't match "Double" in the list. Mention this trade-off if you're asked to justify your choice.
6

Type Check

Catches: input that isn't the kind of data expected — e.g. letters typed where a whole number should be.

hours = input("Hours hired: ")

while not hours.isdigit():
    print("Hours must be a whole number")
    hours = input("Hours hired: ")

hours = int(hours)
Expect: Typing "three" re-prompts; typing "3" moves on and converts cleanly
Exam tip: Check the type before converting with int() — converting first crashes the program on non-numeric input rather than re-asking.
