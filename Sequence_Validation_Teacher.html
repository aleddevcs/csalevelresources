Sequence & Validation

Two short live-coding blocks: first a plain sequence of inputs inside add_record(), then a first validation check on top of it. Keep both deliberately simple — this is a first pass, not the full picture.

Collecting Input as a Sequence

~15 minutes

BEAT 1 · THE ANALOGY

Say: "Think about signing up at a GP surgery or library — you're never asked for your name, then your address, then your name again. It's always the same fields, in the same order."

That's exactly what today's code does: one input() line after another, in a fixed order, directly inside add_record() — no separate function for each field, just like the video walkthroughs.

BEAT 2 · LIVE-CODE THE SEQUENCE

Say: "Let's build this together — one field at a time, then prove it worked with a print."

def add_record():
    name = input("Name: ")
    kayak = input("Kayak type: ")
    date = input("Hire date: ")

    print("Name:", name)
    print("Kayak:", kayak)
    print("Date:", date)
Expect: Each value printed back exactly as entered, in the same order it was collected

BEAT 3 · WHY THIS MATTERS

Ask: "What would go wrong if the input() lines were in a different order to how we eventually want to store them?" — get at least one answer before moving on.

Adding Validation

~10 minutes

BEAT 1 · ASK THE CLASS

Ask: "What could go wrong if a visitor types nothing at all for their name, or just hits enter?" Let students suggest the problem before you show the fix.

BEAT 2 · LIVE-CODE A PRESENCE CHECK

Say: "We keep re-asking until something is actually entered — that's a while loop wrapped around the input."

def add_record():
    name = input("Name: ")

    while name == "":
        print("Name cannot be blank")
        name = input("Name: ")

    kayak = input("Kayak type: ")
    date = input("Hire date: ")
Expect: Pressing enter on an empty name re-prompts; typing anything moves on

BEAT 3 · POINT TO THE REFERENCE SHEET

For confident pairs who finish early in the next task: point them to the Student Reference Sheet for a length check and a range check they can try on a different field. Today's goal for everyone else is just one solid presence check.
