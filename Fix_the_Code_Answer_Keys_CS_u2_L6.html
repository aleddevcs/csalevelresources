THE GAP TYPES

  • 1
    A name that must match its neighbours
    Copy the pattern from the sibling lines.
  • 2
    A method name
    The same method appears on the lines around it.
  • 3
    A counter increment
    The sibling lines use exactly the same counter.
  • 4
    A function name that must match command=
    Check the Button's command= and the def line.
  • 5
    A file name that must match
    Check where the file was opened for saving.
  • O
    Other: a standard line
    The template always has it — see where else it appears.

NOTES FOR MARKING

Accept: any suitable title and message for the saved message (Stock.py line 25). Everything else is exact: the answer has to be the name the file already uses. Likely slips: a missing full stop before ljust; quote marks around a variable name; showinfo without the messagebox. in front; and filling both halves of line 92 in Volunteers.py with the whole word.

Marks: this key gives the answers and the reasoning, not the mark allocation — use the official mark scheme for that. Stock.py has 8 gaps; Volunteers.py has 7 gaps on 6 lines, because line 92 has two.

Checked: every answer here was applied to a copy of the real file and the completed program run, with tkinter stubbed out. Records saved are 150 characters (Stock.py) and 250 characters (Volunteers.py), and the count routines give the right totals.
