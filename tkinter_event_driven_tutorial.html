Project: Tkinter Grade Calculator

What you are building

You are going to create a simple grade calculator using Tkinter, which is a Python library used to build graphical user interfaces (GUIs).

The user will type in three scores, click a button, and the program will calculate the average and display a grade.

Learning goals

  • Create a simple GUI using Python
  • Use an event handler linked to a button
  • Apply variables, input, processing and selection
  • Identify where different programming paradigms appear

Key idea

This is mainly an event-driven program, but it also contains procedural and object-oriented features. Real programs often combine paradigms.

Before you start

  1. Open your Python editor, for example IDLE, VS Code or Thonny.
  2. Create a new Python file.
  3. Save it as grade_calculator.py.
  4. Work through the steps below, testing your code as you go.
Tip: Do not paste the final answer straight away. Build it one section at a time so you understand how each part works.

Step-by-step build guide

Step 1: Import Tkinter

Add the following code at the top of your program:

import tkinter as tk
from tkinter import messagebox

What this does: This imports the tools needed to create the GUI. The message box will be used later if the user enters invalid data.

Paradigm link: Python is often used as a scripting language because code can be written and run quickly without a separate compilation stage.

Step 2: Create the main window

Now create the program window:

window = tk.Tk()
window.title("Grade Calculator")
window.geometry("350x250")

What this does: It creates the main window, gives it a title and sets the size.

Paradigm link: This is also an example of object-oriented programming. The window is an object created from Tkinter.

Step 3: Add a title label

Add this underneath your window code:

title_label = tk.Label(window, text="Grade Calculator", font=("Arial", 16))
title_label.pack(pady=10)

What this does: This adds a heading to the window. The pack() method places the label in the interface.

Paradigm link: tk.Label(...) creates an object. .pack() is a method being called on that object.

Step 4: Add the input boxes

Add three labels and three entry boxes:

label1 = tk.Label(window, text="Enter score 1:")
label1.pack()
entry1 = tk.Entry(window)
entry1.pack()

label2 = tk.Label(window, text="Enter score 2:")
label2.pack()
entry2 = tk.Entry(window)
entry2.pack()

label3 = tk.Label(window, text="Enter score 3:")
label3.pack()
entry3 = tk.Entry(window)
entry3.pack()

What this does: These input boxes allow the user to type in scores.

Paradigm link: The interface is made from objects such as labels and entry boxes. This again shows object-oriented features inside the program.

Step 5: Create a result label

Add a label that will later show the answer:

result_label = tk.Label(window, text="Average:    Grade:", font=("Arial", 12))
result_label.pack(pady=10)

What this does: It creates an area where the result will be shown after the button is clicked.

Step 6: Create the processing function

Now add this function above the code that creates the window:

def calculate_grade():
    try:
        score1 = float(entry1.get())
        score2 = float(entry2.get())
        score3 = float(entry3.get())

        average = (score1 + score2 + score3) / 3

        if average >= 80:
            grade = "A"
        elif average >= 70:
            grade = "B"
        elif average >= 60:
            grade = "C"
        elif average >= 50:
            grade = "D"
        else:
            grade = "Fail"

        result_label.config(text=f"Average: {average:.1f}   Grade: {grade}")

    except ValueError:
        messagebox.showerror("Input Error", "Please enter numbers only.")

What this does:

  • Gets the values from the three entry boxes
  • Converts them into numbers
  • Calculates the average
  • Uses selection to work out the grade
  • Updates the result label
  • Shows an error if the user types invalid data
Paradigm link: The code inside this function is mainly procedural because it runs step by step using sequence, variables and selection.

Step 7: Add the button

Add this underneath your entry boxes:

calculate_button = tk.Button(window, text="Calculate Grade", command=calculate_grade)
calculate_button.pack(pady=10)

What this does: This creates a button. When the user clicks it, the calculate_grade() function is run.

Paradigm link: This is the clearest example of event-driven programming. The program waits for an event. The event is the button click. The function is the event handler.

Step 8: Start the program

Add this final line at the bottom of the program:

window.mainloop()

What this does: This starts the GUI and keeps the program running while it waits for user events.

Paradigm link: mainloop() is central to the event-driven model because it keeps listening for actions such as clicks and keyboard input.

Complete program

Once you have built the program step by step, your finished code should look like this:

import tkinter as tk
from tkinter import messagebox

def calculate_grade():
    try:
        score1 = float(entry1.get())
        score2 = float(entry2.get())
        score3 = float(entry3.get())

        average = (score1 + score2 + score3) / 3

        if average >= 80:
            grade = "A"
        elif average >= 70:
            grade = "B"
        elif average >= 60:
            grade = "C"
        elif average >= 50:
            grade = "D"
        else:
            grade = "Fail"

        result_label.config(text=f"Average: {average:.1f}   Grade: {grade}")

    except ValueError:
        messagebox.showerror("Input Error", "Please enter numbers only.")

window = tk.Tk()
window.title("Grade Calculator")
window.geometry("350x250")

title_label = tk.Label(window, text="Grade Calculator", font=("Arial", 16))
title_label.pack(pady=10)

label1 = tk.Label(window, text="Enter score 1:")
label1.pack()
entry1 = tk.Entry(window)
entry1.pack()

label2 = tk.Label(window, text="Enter score 2:")
label2.pack()
entry2 = tk.Entry(window)
entry2.pack()

label3 = tk.Label(window, text="Enter score 3:")
label3.pack()
entry3 = tk.Entry(window)
entry3.pack()

calculate_button = tk.Button(window, text="Calculate Grade", command=calculate_grade)
calculate_button.pack(pady=10)

result_label = tk.Label(window, text="Average:    Grade:", font=("Arial", 12))
result_label.pack(pady=10)

window.mainloop()

How this program links to programming paradigms

Paradigm How it appears in this program
Event-driven The program waits for the user to click the button. The click is an event, and calculate_grade is the event handler.
Procedural Inside the function, the instructions run in a sequence: input, process, selection and output.
Object-oriented Tkinter creates interface objects such as windows, labels, buttons and entry boxes. Methods like .get(), .pack() and .config() are called on these objects.
Scripting Python allows quick development and testing, which is one reason it is often described as a scripting language.
Important: Although this is mainly an event-driven program, it is not purely event-driven. It combines features from more than one paradigm.
