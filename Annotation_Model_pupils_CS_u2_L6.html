HOW IT IS MARKED (THE 8-MARK VERSION)

7–8 marksAnnotated all eight routines; documented all code beyond self-documenting identifiers (explained the variables); and used appropriate technical terminology confidently and accurately.
4–6 marksAnnotated most of the routines (four to six) and used appropriate technical terminology.

In some years it is worth 4 marks rather than 8: in 2023 it was one mark for each clear annotation of up to four routines, and in 2025 it was banded to 4. This is my paraphrase of the bands; the official mark scheme is the authority.

A NOTE ON VALIDATION IN THIS FILE

pupils.py has no format, length or range checks on what is typed in. The nearest things are the presence check in the count routine, the not ... == "" tests, and the try / except that checks the file exists. Students should annotate what is there, and can say so — rather than inventing a check that isn't in the code.

A MODEL ANNOTATIONThe file pupils.txt is opened in append mode ("a"). If it does not exist yet, Python creates a new blank file; if it does, the new record is added to the end without overwriting what is already stored. fileObject is the file handle used by the following lines to write to it.
What earns the marks

  • Says the file is created if it doesn't exist.

A WEAK ANNOTATIONSaves the data to the file. — only says what the identifier already says.
A MODEL ANNOTATION.ljust(50) pads each field with spaces to exactly 50 characters, making a fixed-length record, so every field starts at the same position in every record. The three padded fields are concatenated into one string with a new-line character (\n) and written to the file as one line with write(). close() then saves the file and releases it.
What earns the marks

  • Names concatenation and the new-line character.
  • Says what close() does.

A WEAK ANNOTATIONReads the file. — only says what the identifier already says.
A MODEL ANNOTATIONThe file is opened for reading inside try / except, so a missing file raises an IOError that is handled with an error message instead of crashing the program. In the else part, readline() reads one record (one line) at a time from the start of the file — sequential access. An empty string means the end of the file has been reached, so the file is closed and break ends the loop.
