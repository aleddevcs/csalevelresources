            if recordVar == "" :

            if FirstnameSave in recordVar[0:50] and not FirstnameSave == "" :

THE GAP DETECTIVE — FIVE GAP TYPES

  • 1
    A name that must match its neighbours
    Copy the pattern from the sibling block: SurnameVar = StringVar()
  • 2
    A method name — .get, .ljust, .showinfo
    The same method appears on the lines above and below.
  • 3
    A counter increment — CountGot += 1
    The sibling lines use exactly the same counter.
  • 4
    A function name that must match command=
    Look at the Button's command=, or the def line.
  • 5
    A file name that must match
    Look at where the file was opened for saving.
The method: find the sibling lines → copy the pattern → still stuck? Ctrl+F — the missing word is almost always somewhere else in the file. If a placeholder sits inside quote marks, a variable name has no quotes.

THE COUNT ROUTINE IN ONE BREATH

CountNeeded = how many boxes were filled in. CountGot = how many of those boxes match this record. A record counts only when they are equal.

  • Reset CountGot = 0 inside the loop, for every record.
  • not X == "" stops an empty box matching every record.
  • in is a partial match: "Al" matches "Alun" and "Alys".
